Controller 1.0.0 is the first direct release for macOS 27 on Apple silicon.

- Project threads for installed coding agents
- File inspection and an integrated terminal
- Signed Sparkle updates with a Check for Updates command
- System-installed Node and coding tools; no bundled coding-tool executables

Download the ZIP, unzip it, and move Controller.app into Applications. Install Node 18 or later and the coding tools you plan to use separately. OpenCode integration expects OpenCode 2.0.3.
